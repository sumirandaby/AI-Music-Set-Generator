# AI-Powered Music Set Generation System 🎧

## About
This is my M.Tech course project for Advanced Multi-Agent Systems. It generates personalized music playlists based on the user's preferred genre, mood, event, and duration.

The system uses AI to discover, rank, and curate tracks automatically.

## Tech Stack
- Python
- Google Gemini API
- LangGraph
- Last.fm API
- Streamlit

## Features
- Personalized music recommendations.
- AI-based planning and playlist curation.
- Music discovery using Last.fm.
- Duplicate-version filtering.
- Maximum two tracks per artist.
- CSV playlist export.

## Run Locally

```bash
git clone https://github.com/sumirandaby/AI-Music-Set-Generator.git
cd AI-Music-Set-Generator
pip install -r requirements.txt
streamlit run app.py
```
